What your child builds

This isn't drag-and-drop blocks or watching videos. From the first weeks, kids write real Python and run real programs — and every concept lands as something they can show off. Our course is built around roughly 70 build projects (we call them quests), so progress is measured in things made, not chapters read.

  • Playable games — guessing games, a number-dueling arcade, text adventures
  • Turtle-graphics art — spirals, mandalas, and generative designs drawn by code
  • Fractals — patterns that repeat inside themselves, built from a few lines of logic
  • A chatbot that responds to what you type and remembers the conversation
  • Tools they invent — a quiz maker, a dice roller, a secret-message encoder, whatever they imagine

By the end, your child won't just have "done Python." They'll have a folder full of programs they wrote themselves — and the confidence that comes with it.

Taught from first principles

Most beginner coding teaches syntax to memorize: type this, get that. We do the opposite. We teach what each building block actually is — so a student can write any program, not just the one in the lesson.

Take a loop. Instead of memorizing a line to copy, a student learns the idea: a loop repeats a step until a condition is true. Once that clicks, they can write a loop to animate a game, draw 200 petals of a flower, or keep asking a question until the answer is right. One idea, understood deeply, unlocks hundreds of programs. We do the same with variables (a labeled box that holds a value), functions (a named recipe you can reuse), and conditions (a yes/no fork in the road).

We're honest about what this takes: real coding means real debugging. When a program breaks — and it will — we treat the error as the interesting part, and kids learn to read it, reason about it, and fix it. That's the skill that lasts.

How it works

  • Weekly classes, year-round, with rolling enrollment
  • Small groups so every student gets real mentor attention
  • Build-first: kids write and run code every session, from day one
  • Self-paced within the group — strong coders push ahead, newcomers get support
  • $100 per month — no prior coding experience required

All a student needs is curiosity. We supply the mentors, the method, and the momentum.
